deployment_rule_snapshots
COLUMNTYPE / NOTES
idUUID PK
deployment_idUUID FK → deployments
rule_idUUID FK → rules
rule_snapshotJSONB — full rule at deploy time
drl_blockTEXT — rendered DRL for this rule
Snapshot captures rule state at deploy time — rules can change later without affecting history.
Key design choice: Rules store both condition_raw/action_raw (exact DRL text — used when importing existing .drl files) and condition_meta/action_meta (structured JSONB — used by the visual condition/action builder). Imported rules start with raw only; rules created via builder have both.
