FRONTEND (React + Vite)

Condition/action builder + DRL live preview

Create/manage clients, import DRL files

Version snapshots + DRL bundle export

🔌 REST API
CRUD for rules, clients, deployments
⬆️ DRL Importer
Parse .drl files → structured rules in DB
⬇️ DRL Generator
Reconstruct valid .drl from stored rules

Bundle all rule types as ZIP for deployment
